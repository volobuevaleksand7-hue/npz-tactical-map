Методика расчёта индекса

Что считается

(0–100) рассчитывается отдельно для восьми регионов и мира целиком. Расчёт детерминированный и выполняется скриптом по открытым рядам данных; языковые модели число не определяют. Оценка носит характер OSINT и не является официальными данными.

Нормировка

Каждый компонент переводится в балл 0–100 как процентиль текущего значения к его истории: для цен — за 3 года, для остальных рядов — за 5 лет. Для проливов «падение трафика» — 7-дневное среднее относительно медианы за 365 дней. Для мыса Доброй Надежды рост трафика читается как обход, то есть сигнал.

Формула

значение региона = Σ (балл · вес) / Σ (веса доступных компонентов)
покрытие = Σ весов доступных компонентов
  • Пропуск компонента не перераспределяет вес: недостающее не заменяется оценкой, а снижает покрытие.
  • Покрытие ниже 50% — значение не показывается («мало данных», серая штриховка на карте).
  • Ряд устарел (старше двух периодов обновления) — компонент выпадает, покрытие падает.
  • Мировой индекс — среднее по регионам с весами импорта (константы заданы в скрипте расчёта).

Уровни

0–24 спокойно · 25–49 напряжённо · 50–74 кризис · 75–100 критично.

События

События на балл не влияют. Карточки событий — редакторский слой: публикуются только проверенные скриптом и одобренные владельцем записи. «Подтверждено» — минимум два независимых издателя; «по сообщениям, один источник» — единственный источник. Текст «влияние на индекс» появляется лишь когда его подтверждает смена ряда.
