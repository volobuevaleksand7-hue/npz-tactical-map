# Жёсткие правила проекта

## Тон и контент

- **Нейтральный русскоязычный OSINT-тон — обязателен для ВСЕГО публикуемого текста** (статьи, сводки, `data/strikes.json`). Запрещено: вербатим-репосты Telegram-каналов, украинский язык в данных, пропаганда/лозунги любой стороны, офф-топик (сбитые самолёты/лётчики), `confidence` вне `confirmed|reported|rumored`. Гарант — `agents/censor.py` (для HTML) и `agents/sanitize-strikes.py` (для JSON) в `.githooks/pre-commit`; оба вычищают и перезакладывают файл сами, коммит блокируется только если автоправка не справилась (явный лозунг/призыв). Осознанная цитата в разборе → `ALLOW_CENSOR_OVERRIDE=1`.
- **⛔ Никогда не отмечать ПВО на карте.** Запрещены метки/иконки/бейджи/подсветка позиций и активности ПВО на любом слое `/radar` — юридическое ограничение, не стилистика. Текст новостей (сырые сообщения ленты) фильтровать НЕ нужно, это отдельное ограничение только для карты (`api/radar-state.js` режет флаг `pvo` из городов/регионов).
- Каждый показ данных на сайте несёт дисклеймер «ОЦЕНКА» — это OSINT-агрегация, не официальные данные.
- Даты в видимом UI — русский формат («7 июля 2026»), не ISO. Время — всегда МСК.

## Деанон-границы (проект анонимный, репозиторий публичный)

- Публичные кнопки Telegram (`@NPZmap`, `@NpzFuel_Bot`) и `mailto:` на личную почту владельца **убраны с сайта намеренно** (2026-07-07) и не возвращаются в публичный UI. Новые брендированные сущности (`@npz_karta`, `@npz_karta_bot`, `@npz_karta_online` — см. `docs/agents/TELEGRAM_CONTOUR_2026-07-31.md`) вешать можно, старые — нет.
- Аккаунт `@npz_karta` брендирован под НПЗ-проект — с него нельзя писать по другим проектам владельца, это свяжет анонимный проект с личностью.
- Коммит-identity анонимная (`agent@volobuevaleksand7-hue` и т.п.) — **никогда не коммитить под реальным именем/почтой**. `Co-Authored-By: Claude` в коммите на анонимном репо — тоже лишний след, вычищать amend'ом.
- GitHub push — только точечным токеном на команду (`GH_TOKEN=$(gh auth token -u volobuevaleksand7-hue) git ...`). `gh auth switch` не использовать никогда — глобальная настройка машины, ломает параллельные сессии других проектов.

## Защита оболочки и данных

- **UI-shell защищён pre-commit хуком**: `index.html`, `styles.css`, `app.js`, `radar.html`, `version.json`, `CHANGELOG.md`, `.vercelignore`. Коммит с этими файлами требует `ALLOW_FRONTEND_RELEASE=1` + SemVer-бамп + запись в `AGENT_ACTIVITY.md`. Подробности и почему — `memory/decisions/ui-shell-release-gate.md`.
- Cron/Hermes-агенты не трогают оболочку и release-файлы без явного запроса на UI-релиз.
- Агенты-сборщики меняют только статусы/даты/дефицит/события/`meta` в `data/fuel-state.json`. Координаты, названия, мощности объектов — не трогать.
- **Никогда не запускать `git pull --rebase --autostash`, `git add -A` или `git reset --hard` в общем рабочем дереве** (`~/Documents/npz-tactical-map` на Маке, `/root/npz-tactical-map` на VPS). Данные — только через `agents/git-sync.sh`. Долгая/многофайловая работа — в отдельном `git worktree`. Подробности — `memory/facts/shared-worktree-git-hygiene.md`.
- `data/strikes.json` и `data/fuel-voices.json` — накопительные архивы, коллекторы только дописывают, никогда не перезаписывают снапшотом целиком. Обход усечения — только осознанно (`ALLOW_STRIKES_SHRINK=1` / `ALLOW_VOICES_SHRINK=1`).
- Обложки сводок (сайт `/news` + Telegram) рендерит только Codex (`hermes/scripts/build-covers.py`). Не рисовать самому, не звать другую модель для генерации картинки.
