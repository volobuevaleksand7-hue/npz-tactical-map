# Индикаторы здоровья флота лгут — проверять данные, не плашку

## Что сломается, если не знать

Потратишь время на «реанимацию» живых агентов, или, наоборот, пропустишь реальную деградацию, приняв ложную тревогу за очередной шум.

## Случай 1 — heartbeats.json обнулён чужим коммитом, агенты живы

25.07.2026: плашка «⚠ 5 агентов не на связи» была ложной. В 00:26 не связанный с агентами коммит `data(fuel-availability)` обрушил `data/heartbeats.json` с 12 ключей до 1 (побочный эффект `git add data/` соседней рутины — тот же класс, что `memory/facts/regenerator-drops-manual-fields.md`). `healthcheck.py` честно объявил живых мёртвыми; файл сам заживал по мере кронов агентов (1→8→12 ключей). Корень: промпты 5 агентов требовали писать heartbeat вручную через bash-heredoc, но у них НЕТ Bash-тула — LLM имитировал запись через `Write` и терял чужие ключи; JSON оставался ВАЛИДЕН, поэтому защита «не парсится» не сработала.

**Диагностическое правило:** «N агентов не на связи» ≠ агенты мертвы. Сначала смотреть число ключей в `data/heartbeats.json` по истории коммитов, потом — логи конкретного агента.

## Случай 2 — окно с TTL спутано с накопительным архивом при выборе метрики гварда

19.08.2026: healthcheck объявил `degraded` — `fuel-voices.json` «усох» 327→200. Ложная тревога: все 167 выпавших записей имели `seen` старше 21 дня — штатный TTL из `agents/update-prompt-voices.md` (плюс 40 новых цитат тем же прогоном). `fuel-voices` — **скользящее окно, не накопительный архив**, но его завели в проверку `healthcheck.py` вместе со `strikes.json` (там базой служит исторический максимум) — максимум для окна с TTL недостижим по определению, тревога держалась бы вечно и глушила настоящие сигналы. Фикс: окна вынесены в отдельную категорию `WINDOWS`, стерегутся ПОЛОМ (минимум 50 записей — ловит настоящее обнуление вроде падения 96→0), а не историческим максимумом.

## Правило

Перед тем как заводить новый файл в проверку здоровья флота — определить его природу: **накопительный архив** (гвард по историческому максимуму / >10% усыхание уместен) или **скользящее окно с TTL** (нужен только пол на абсолютное число, максимум недостижим и бессмысленен).
