# Headline-метрика дрейфует, когда LLM пересчитывает её на каждом синке

## Механизм

`national_balance` в `data/fuel-state.json` хранит агрегаты (`capacity_offline_*` и др.), которые ДОЛЖНЫ детерминированно выводиться из таблицы `refineries[]`. Пока их писал LLM-агент на каждом прогоне синхронизации, у него под рукой было ДВЕ похожие метрики — доля полностью выбитых заводов (`capacity_offline_pct`, по собственной таблице 38.5%) и недобор с учётом частично работающих (`throughput_shortfall_pct`, 64%) — и агент периодически путал поля, обе метрики становились одинаковыми, чего быть не может при разных определениях.

## Рецидивы (минимум 3, по разным поверхностям)

1. 25.07.2026 — headline на главной странице показывал «мощностей выбито полностью 64%» вместо верных 38.5% (завышение в 1.7×).
2. Копия той же формулы разъехалась во втором месте пайплайна (упомянуто как повтор класса в записях после 25.07).
3. Прозаический текст (`national_balance.notes`, генерируемый LLM) говорил «11-12 НПЗ, 143-145 млн т, 42-43%» — не сходилось с табличными данными; отдельно прозаическая формулировка «11 из 33 = треть мощностей» на деле означала 40% — доля заводов и доля мощностей смешивались текстом.

## Фикс

`agents/recalc-national-balance.py` — детерминированный пересчёт национального баланса из `refineries[]` (не из головы модели), с `--check`/`--demo`. Вызывается АВТОМАТИЧЕСКИ в `.githooks/pre-commit` при коммите `data/fuel-state.json` — гвард пересчитывает и перезакладывает файл (не блокирует, см. `memory/decisions/guard-block-vs-autoheal-policy.md`), заодно дописывает точку в `data/capacity-timeline.json`, если процент изменился с последней сохранённой точки.

## Что я сломаю, если не буду это знать

- Доверюсь прозе LLM-агента про «долю заводов»/«долю мощностей» без сверки с таблицей `refineries[]` — процитирую неверную цифру в статье или сводке.
- Напишу похожий пайплайн с двумя близкими по смыслу метриками, вычисляемыми текстом на каждом прогоне, без единого детерминированного источника — получу тот же класс дрейфа через несколько недель эксплуатации.
