# Эталон рилса — 04.10.2026

Образец, по которому собирается каждый ежедневный рилс: https://youtu.be/z8wWCO9tldg
(«5 ударов по РФ · 04.10.2026 #shorts», 44 с, 1080×1920). Владелец: «делать не хуже».
Соответствие проверяет `reel/audit.py` — при жёстком провале `daily.sh` не публикует.

## Источник
- Удары — `data/strikes.json`, тот же файл, что слой ударов на основной карте и на `/karta-bpla`.
- Берутся удары дня (МСК) с координатами, `confirmed|reported`; слухи (`rumored`) — нет.
- Один город — одна остановка камеры; порядок: топливо/энергетика → промышленность → прочее.
- Перед рендером `daily.sh` запускает свежий проход сборщика ударов (данные дня докатываются с опозданием).

## Структура (04.10: 43.8 с, 5 остановок)
| Блок | Длительность | Что на экране |
|---|---|---|
| Постер | 1.3 с | «N УДАРОВ ПО РФ» (или «УДАР ПО <объекту>» в дательном падеже), 3 города, дата, «ОЦЕНКА · OSINT» |
| Общий план | 1.1 с | вся карта дня, пульсирующие точки |
| Остановка × N | ~5–8 с | перелёт 1.6 с → плашка: тип (ПРОМЫШЛЕННОСТЬ/ОБЪЕКТ/…), дата · подтверждено/сообщается, **город**, объект, 1–2 строки факта |
| Клип (если есть) | 2–3 с | кадры очевидцев на месте удара, подпись источника |
| Итог | 5 с | «N ударов за сутки», разбивка топливо/прочее, регионы, сайт + @npz_karta_online, дисклеймер «ОЦЕНКА» |

## Озвучка
- Голос `ru-RU-DmitryNeural` (edge-tts), темп `+25%`, громкость ×1.5.
- Вступление: «Четвёртое октября. Пять ударов по России за сутки. По данным открытых источников.»
- По удару — **одна фраза 70–120 знаков**: «Город: что случилось на объекте, итог.» Не больше двух фактов,
  без перечня районов и россыпи цифр. Если города нет — область.
  Пример: «Калуга: при атаке на завод Восход вспыхнул пожар, ранены несколько человек.»
- Финал: «Карта всех ударов — по ссылке в описании.»
- Реплика стартует вместе с перелётом к удару (whoosh), т.е. голос и камера синхронны.

## Текст плашки
- Тот же смысл, что озвучка (плашка = реплика без «Город:»), без обрезки многоточием.

## Звук
- Музыкальная подложка `gen-svodka.wav`, громкость 0.32, fade-in 1.2 с, fade-out 1.8 с.
- Эффекты: `impact` на постере и на итоге, `whoosh` на каждом перелёте, `click` на появлении плашки.
- Музыка приседает под эффекты (sidechaincompress threshold 0.03, ratio 8), лимитер 0.95.

## Расписание
- **Рилс дня — каждый день в 12:00 МСК** за вчерашний день (полный день, как эталон 04.10):
  cron Гермеса 08:00 UTC → проход сборщика ударов → рендер → аудит → ожидание до 09:00 UTC → публикация.
- **Срочный рилс — без расписания:** `hermes/bot/strike_pipeline.py` после молнии (TIER 1) запускает
  `REEL_KIND=urgent REEL_ONLY=<id> reel/daily.sh <сегодня>`; публикуется сразу, один на дату
  (`out/urgent-<дата>.uploaded`). Постер «УДАР ПО …», вступление «Срочно. …», итог «СРОЧНО». Выключатель `NPZ_URGENT_REEL=0`.
