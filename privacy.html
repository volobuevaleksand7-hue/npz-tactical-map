Политика конфиденциальности

Сайт «Топливный фронт РФ» и связанный с ним YouTube-канал публикуют сводки по открытым источникам.

Приложение для YouTube

Наше приложение в Google Cloud использует YouTube Data API только для одного: загружать ежедневные ролики-сводки на наш собственный канал. Оно запрашивает единственное разрешение — загрузку видео (youtube.upload) — и работает только с аккаунтом владельца канала.

Приложение не читает, не хранит и не передаёт данные других пользователей YouTube или Google. Токен доступа хранится только на нашем сервере и используется исключительно для загрузки наших роликов.

Сайт

На сайте работает обезличенная веб-аналитика (Яндекс Метрика) для подсчёта посещаемости. Мы не собираем имена, адреса электронной почты или иные персональные данные посетителей.
