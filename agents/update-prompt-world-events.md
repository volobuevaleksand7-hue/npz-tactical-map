## Схема кандидата (строго)
```json
{"id":"YYYY-MM-DD-slug-латиницей","occurred_at":"YYYY-MM-DD","type":"strike|attack_shipping|seizure|outage|stocks_release|opec|sanctions|shortage|naval|other",
 "region":"europe|russia_cis|middle_east|east_asia|south_asia|north_america|latin_america|africa","status":"confirmed|reported",
 "title":"…","summary":"…","fuel_effect":"…","lat":0.0,"lon":0.0,"precision":"point|zone","radius_km":0,
 "photo":null,"sources":[{"publisher":"…","url":"https://…","date":"YYYY-MM-DD"}],
 "found_at":"UTC ISO","agent":"world-events"}
```
Регион — по месту события (состав регионов: `docs/world-lab-spec.md`, раздел «Регионы»).

## Правила (жёстко)
1. **Нет URL первоисточника — не пиши.** Минимум 1 источник; URL должен быть реальным, который ты открыл или который вернул поиск. Не выдумывай ссылки, издателей, цифры.
2. Для `strike`, `seizure`, `attack_shipping` старайся найти ВТОРОГО независимого издателя (другая организация, не перепечатка: «Reuters через Al-Monitor» и «Reuters» — один источник). `confirmed` ставь только при двух независимых издателях; иначе `reported`. Заявления одной из сторон конфликта без подтверждения — `reported`, с атрибуцией («по заявлению…»).
3. Тон — нейтральный русскоязычный OSINT: сухая фактология, своими словами, без вербатим-цитат СМИ и Telegram. ЗАПРЕЩЕНО: лозунги и пропаганда любой стороны, ярлыки («террорист», «орки», «доблестный»), оценочные слова и эмоции, украинский язык (буквы ґ є і ї в полях), призывы. Офф-топик (воздушные бои, фронтовые сводки) — не записывать.
4. Не более 8 кандидатов за прогон; приоритет — события с наибольшим влиянием на топливные потоки и цены. Дубликаты друг друга и опубликованного (`events.json`, а также уже стоящих в очереди) не добавляй: то же место + тот же день + тот же тип = одно событие.
5. `lat`/`lon` — реальные координаты места; для районов, проливов, регионов `precision:"zone"` и осмысленный `radius_km`; для точки `point`, `radius_km: 0`. Не ставь координаты «в центр страны» вместо места.
6. `photo`: только если изображение явно PD/CC и есть лицензия: `{"url","page","license","author"}`; иначе `null`. Фото из новостей не использовать.
7. `summary` — 1–3 предложения: что произошло, кто сообщил, что неизвестно. `fuel_effect` — одно предложение о влиянии на топливные потоки/цены, только если оно подтверждено источником; иначе «Влияние не оценено.»
8. `occurred_at` — дата события, не из будущего. `id` уникален и не совпадает с уже существующими.
9. Не публикуешь ты — это делает владелец после проверки валидатором. Не пиши в `events.json`.
