## Правила исполнения (общие)

- Свой git worktree от `origin/main`, работа в общем дереве запрещена, `git add -u/-A` нельзя.
- 🔴 Коммить и пушить сразу: фоновый git-sync периодически откатывает рабочее дерево.
- Push: `GH_TOKEN=$(gh auth token -u volobuevaleksand7-hue) git push origin HEAD:main`, перед
  push `git fetch origin main && git rebase FETCH_HEAD`. `gh auth switch` запрещён.
- Фронтенд-коммит с префиксом `ALLOW_FRONTEND_RELEASE=1`. Push сам запускает CI-деплой;
  локально `vercel` не запускать, дождаться зелёного прогона и проверить прод живьём.
- Правишь страницу завода — прогони `python3 agents/gen-refineries.py --check`. Правишь
  генерируемую страницу — правь генератор, не HTML.
- 🔴 Факты только из `data/`. `confidence: reported` → «сообщается», не «подтверждён».
- 🔴 Тон нейтральный OSINT-русский (в pre-commit цензор). ПВО на картах не отмечать. Даты в UI
  по-русски. Атрибуция Leaflet без флагов.
- 🔴 Числа в статьях сверять с `data/` перед тем, как считать пункт сделанным. Отчёты агентов
  проверять по исходникам: за прошлую очередь дважды всплывало расхождение, которое агент не
  заметил (в том числе цифра, изменившаяся в данных уже после выдачи задания).
