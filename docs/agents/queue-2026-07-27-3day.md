## Правила исполнения (общие для всех пунктов)

- Свой git worktree от `origin/main`, работа в общем дереве запрещена. `git add -u/-A` нельзя.
- Push: `GH_TOKEN=$(gh auth token -u volobuevaleksand7-hue) git push origin HEAD:main`,
  перед push — `git fetch origin main && git rebase FETCH_HEAD`. `gh auth switch` запрещён.
- Фронтенд-коммит с префиксом `ALLOW_FRONTEND_RELEASE=1`. Push сам запускает CI-деплой.
- Новая страница — запись в реестре ДО публикации, затем `python3 agents/build-nav.py`.
- 🔴 Тон строго нейтральный OSINT-русский (в pre-commit цензор). ПВО на картах не отмечать.
  Даты в UI по-русски. Факты только из `data/` — не выдумывать событий.
