## In-session decisions
- **Поражения складов выводятся из `strikes.json`, не хардкодятся** — иначе слой
  расходится со слоем ударов (уже случалось: 4 объекта вместо 6).
- **Матчинг удар↔склад: уточнение из скобок по имени, потом геометрия.** Только
  `inner`, не город до скобки: по городу общегородская сводка ложно помечала
  поражённым конкретный склад в Парголово (проверено экспериментом).
- **Подгруппы меню — регуляркой, а не списком URL** (список протухал на каждой
  новой статье, меню отрастало в портянку 55 строк).
- **`git-sync` больше не уничтожает правку молча** — сначала копия в
  `.claude/discarded/<стамп>/`, потом сброс. Дважды за сутки стирал работу.
- **Страж зон в `.githooks/pre-commit`** против чужого `git add -A`.
  🔴 Хук исполняется на macOS И Linux — проверять на обеих (мой `stat -f` на
  Linux обвалил все коммиты VPS на час).
- **Корень падений `fuel-market`** — промпт требовал переписывать 64 КБ целиком
  через Write. Заменено на точечный Edit; ретрай на битый JSON — страховка.
