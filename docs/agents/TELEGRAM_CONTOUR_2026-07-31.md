## 2. Автопостинг сводок (уже работает)

Сводки идут **в два канала сразу**: боевой `@NPZmap` и новый `@npz_karta_online`.

- Скрипт: `/root/npz-tactical-map/hermes/bot/broadcast.py` (бэкап `broadcast.py.bak-20260731`).
- Постит бот `@NpzFuel_Bot` (id `8752002850`, токен `/root/.npz-bot/token`) — он получил
  админку в новом канале с правами `post_messages` + `edit_messages`
  (второе обязательно, иначе режим `--update` не сможет править пост в зеркале).
- Переменная `NPZ_CHANNEL_MIRRORS` — список зеркал через запятую, дефолт `@npz_karta_online`.
  Пустая строка отключает зеркала и возвращает прежнее поведение.
- `do_briefing` шлёт ту же картинку и тот же текст в каждое зеркало; id сообщений пишутся в
  `state["mirrors"][<канал>]`, отдельно от основных `media_message_id`/`text_message_id`.
- `do_update` применяет правку (caption / text / переход caption→split) и к зеркалам.
- Ошибка зеркала логируется, но не роняет публикацию в основной канал.
- Cron не менялся: `0 7 * * *` и `0 19 * * *` UTC = 10:00 и 22:00 МСК.
- Коммит: `e50ebeea` в `volobuevaleksand7-hue/npz-tactical-map`.

```bash

ssh hermes-vps 'cd /root/tg-recon && ./.venv/bin/python sessions.py'

# кто владелец канала, кто админы (скрипт audit.py там же)
ssh hermes-vps 'cd /root/tg-recon && ./.venv/bin/python audit.py'

# живость бота под виджет
ssh hermes-vps 'curl -s "https://api.telegram.org/bot$(cat /root/.npz-site-bot/token)/getMe"'
```

Ожидаемые сессии аккаунта — ровно две: юзербот (`PC 64bit / Telegram Desktop`, Kansas City) и
вход владельца (`Chrome / macOS / Telegram Web`, Los Angeles — он ходит через антидетект-браузер
с американским прокси). Третья сессия или неамериканское гео = тревога.

🔴 Сессию юзербота не завершать никогда: на ней держатся владение каналом и вся автоматизация.
Кнопка «Завершить все другие сеансы» убивает именно её.
