# Зоны сессий

Механизм против коллизий параллельных сессий в этом репозитории.

## Зачем

01.08.2026 за один день: чужой `git add -A` утянул правку соседней сессии в свой
коммит, а `git-sync` дважды снёс незакоммиченную работу. Корень один — сессии не
знают друг о друге.

## Как пользоваться

1. В начале работы объяви зону — файл `<имя>.zone` со списком regex-путей
   (по одному в строке, `#` — комментарий):

   ```
   echo '^app\.js$
   ^index\.html$' > .claude/zones/karta-ikonki.zone
   ```

2. Экспортируй имя своей зоны, чтобы хук не ругался на твои же файлы:

   ```
   export NPZ_ZONE="karta-ikonki"
   ```

3. Закончил — удали файл зоны.

## Что делает хук

`pre-commit` блокирует коммит, если в индекс попал файл из **чужой** зоны, которая
изменялась меньше 8 часов назад (`NPZ_ZONE_TTL_H`). Протухшие зоны игнорируются —
забытый файл не блокирует репозиторий навсегда.

Обход на один коммит, когда правка действительно общая:

```
ALLOW_CROSS_ZONE=1 git commit -m "..."
```

## Что это НЕ делает

Не мешает читать и править файлы — только не даёт закоммитить чужое скопом. Это
предупреждение о пересечении, а не блокировка работы.
